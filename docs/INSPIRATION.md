# Sources, inspiration, and visual credits

## Repositories reviewed

Reviewed on 2026-10-19. These references informed organization and usability. No external prompt text or source code was copied into the new prompt library.

| Reference | What informed this repository |
| --- | --- |
| [Anthropic skills](https://github.com/anthropics/skills) and its [template](https://github.com/anthropics/skills/blob/main/template/SKILL.md) | A self-contained folder with a short skill entrypoint and task-specific supporting resources |
| [Fabric](https://github.com/danielmiessler/Fabric) and [extract_wisdom](https://github.com/danielmiessler/Fabric/blob/main/data/patterns/extract_wisdom/system.md) | Named, reusable patterns that connect a stated purpose to a recognizable output |
| [prompts.chat](https://github.com/f/prompts.chat), formerly Awesome ChatGPT Prompts | A browsable catalog and copyable examples that make selecting a behavior approachable |

Essentiabot keeps its own constraints: evidence coverage is explicit, output length scales to the material, and an opposing argument is not fabricated source evidence. The named philosophical prompts are contemporary practical adaptations. Their labels identify the perspective used; they do not claim scholarly completeness or historical authorship.

The hero's generation brief: a wide editorial banner on a dark navy background; overlapping page fragments, video frames, and waveforms pass through a luminous mint glass prism and become three ordered evidence cards; restrained glow, no readable text, logos, people, or watermark. The diagrams use matching navy, mint, and amber accents with actual text for readability.
