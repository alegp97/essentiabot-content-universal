# User manual

## Ask for an analysis

Invoke the skill using the host's mechanism, or mention Essentiabot in your request:

> Use Essentiabot to analyze this article. Explain what is useful, what needs verification, and what is hype: [URL]

For a shorter response:

> Summarize this link in five bullets and identify the two weakest claims.

For a chosen language:

> Use Essentiabot to analyze this video in Spanish. Say whether the analysis is based on captions or metadata.

For images:

> Analyze the attached infographic. Separate visible text, your interpretation, and claims needing evidence.

For comparisons:

> Compare these two sources. Identify agreements, contradictions, missing evidence, and which is worth studying.

## Read the result

A substantive report can cover summary, thesis, useful ideas, evidence quality, hype, practical value, information SWOT, and a save/study/ignore/investigate verdict. Sections should shrink with the evidence available. A title or thumbnail alone cannot support a verdict about an entire video.

The assistant should identify whether it used a transcript, page text, caption, metadata, or actual image inspection. Automatic captions can contain transcription errors. An extracted assertion remains a source claim until verified.

## When a source cannot be accessed

The assistant should state the observed failure and use any partial material already available. You can provide the article text, captions, transcript, screenshots, or an attachment. Supplying the missing material is often enough; you do not need to configure Instagram for ordinary web analysis.

The skill never publishes or sends the analysis automatically. A link to a source does not authorize account changes or public posting.
