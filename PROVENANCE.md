# Provenance

This release adapts the owner's installed `essentiabot-content-portable` plugin, version 0.4.0, into a standalone skill. Original extractor modules have been retained and modified; instruction and documentation files have been rewritten for this release.

The original private Instagram configuration and bundled third-party dependencies were not copied. No credential values were needed to build this release. Optional third-party packages remain subject to their own licenses when installed separately.

The conversion does not determine ownership of every original component or grant a new license on the rights holder's behalf. No open-source license is assigned here. The rights holder may add their chosen license after confirming the relevant rights. Preserve this provenance note when distributing adaptations.
